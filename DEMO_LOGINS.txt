How the staff accounts work:
- These three addresses are listed in TEST_STAFF in auth.py. Only these three
  non-@cu.ac.bd inboxes may create a staff account, and each gets the role above.
- There is NO fixed password. The first time, use the staff sign-up: enter the
  address, enter the code emailed to that inbox, and choose a password.
  Forgot it? Use the reset flow, which also emails a code.
- If email sending is off (mailer.py), the code is shown on the page instead
  (SHOW_CODE in auth.py: 1 = only when email failed, always, 0 = never).
- Wrong passwords: 5 tries, then locked for 15 minutes. Codes last 10 minutes.
